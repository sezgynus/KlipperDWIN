# Screenshot assets / Ekran görselleri

[English gallery](../../screenshots.md) · [Türkçe galeri](../../screenshots_TR.md)

Original-size 272×480 RGB PNGs rendered through the real Petrel UI and emulator. Keep existing filenames stable for external links. See the [emulator guide](../../ui-emulator.md) to capture a live screen or regenerate the documentation set.

Gerçek Petrel arayüzü ve emülatörle üretilmiş özgün boyutlu 272×480 RGB PNG görselleridir. Dış bağlantılar için mevcut dosya adlarını koruyun. Canlı görüntü alma ve dokümantasyon setini yeniden üretme için [emülatör rehberine](../../ui-emulator_TR.md) bakın.
## Presentation copies / Sunum kopyaları

`framed/` contains 528×900 enclosure composites with the original panel pixels placed without resampling. Native files above remain 272×480. Regenerate both with `tools/render_docs_screenshots.py --frame`; see the [complete PNG/GIF workflow](../../ui-emulator.md#refresh-pngs-frames-and-gifs).

`framed/` içinde özgün panel pikselleri yeniden örneklenmeden yerleştirilen 528×900 çerçeveli sunum kopyaları bulunur. Üstteki özgün dosyalar 272×480 kalır. İkisini `tools/render_docs_screenshots.py --frame` ile yenileyin; [tam PNG/GIF akışına](../../ui-emulator_TR.md#png-çerçeve-ve-gif-yenileme) bakın.
